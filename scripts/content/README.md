# Content pipeline (rewritten chapters and topic quizzes)

- `src/data/chapters/<topicId>.json` replaces the generated chapter with the same id (loaded in `src/data/crtCourseData.ts`).
- `src/data/topicQuizzes/<topicId>.json` is the quiz shown at the bottom of that chapter (`TopicQuiz` component). To add questions later, edit this file only: append to `questions` with the next `id`, 4 `options`, `answerIndex` (0-3), `explanation`, optional `shortcut`.
- `scripts/content/year1/*.cjs`, `year2/*.cjs` and `year3/*.cjs` are the authoring sources (3rd Year chapters use the compact helper `chap.cjs`). Run `node scripts/content/runAll.cjs year1` (or `year2`) to regenerate the JSON files; for 1st Year also run `node scripts/content/patchGoodChapters.cjs` (ch 1-6). `diLib.cjs` holds helpers for data-interpretation quizzes.
  If you edit a JSON file by hand, do not re-run the generators afterwards (they overwrite it).
- `node scripts/content/verify.cjs y1` checks every quiz and chapter (4 options, unique options, valid answerIndex, no placeholder text, 3+ solved examples).
- `node scripts/content/checkNumeric.cjs` independently recomputes 215 numeric answers of 1st Year ch 1-12; `checkNumeric2.cjs` does 109 for 2nd Year ch 1-20.
- 3rd Year helpers: `chap.cjs` (compact chapter builder), `year3/puzzleLib.cjs` (brute-force solver for seating, floor, box, scheduling and matrix puzzles; a puzzle fails to build unless its solution is unique, and every answer is computed from the solution), and the models in `year3/ch36_37.cjs` (Venn-model check for syllogisms), `year3/ch42_43.cjs` and `year3/ch69_70.cjs` (data-sufficiency checks over all possible worlds), `year3/ch44.cjs` (rule engine for decision problems). DI quizzes compute every answer from the dataset in the file.
- `node scripts/content/checkArith3.cjs y3` recomputes every "expression = number" fragment in the 3rd Year explanations and chapters (850 fragments; the few reported mismatches are parser artefacts such as a missing leading factor or a percent sign, reviewed by hand).
