# RIET CRT PDF REPOSITORY

Place the official RIET College CRT Study Material PDFs in their respective folders:

- `public/pdfs/quantitative/`
- `public/pdfs/reasoning/`
- `public/pdfs/verbal/`
- `public/pdfs/programming/`
- `public/pdfs/technical/`
- `public/pdfs/communication/`
- `public/pdfs/interview/`

When a PDF file is dropped here (e.g. `percentages.pdf`), update the `hasPdfFile: true` and `pdfUrl` in `src/data/syllabusData.ts`.
The LMS system will automatically render the PDF directly inside the learning material viewer!
